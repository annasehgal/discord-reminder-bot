# Use the GNU Affero General Public License v3

## Context and Problem Statement

The project needs an open-source license that defines how the software can be
used, modified, and redistributed.

Which license should be used for the project?

## Considered Options

- MIT License
- GNU Affero General Public License v3 (AGPL-3.0)

## Decision Outcome

Chosen option: "GNU Affero General Public License v3 (AGPL-3.0)", because

- It allows others to use, modify, and redistribute the software.
- It requires modified versions to remain available under the same license.
- It includes requirements for software made available to users over a network.
- It provides stronger copyleft protections than the MIT License.

## Consequences

### Positive

- The project remains open source.
- Improvements and modifications are expected to remain available under the same license.
- The license provides strong copyleft protections for the project.
- Users can access, modify, and redistribute the software under the license terms.

### Negative

- AGPL-3.0 has stronger requirements than permissive licenses such as MIT.
- Developers incorporating the project into other software must comply with the
  AGPL-3.0 license requirements.
